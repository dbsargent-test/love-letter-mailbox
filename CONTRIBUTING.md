# Contributing

Thanks for your interest! This is a personal project, but contributions are welcome.

## How to Contribute

1. **Fork** the repo and create a feature branch
2. **Make your changes** — keep commits focused and descriptive
3. **Test** your changes (especially hardware dimensions if touching the enclosure)
4. **Open a PR** with a clear description of what and why

## Areas of Interest

- ESP32-C5 firmware (Arduino C++ or MicroPython)
- Web app improvements (vanilla JS, Azure Functions backend)
- Enclosure design (OpenSCAD parametric)
- Documentation and build guides

## Questions?

Open an issue — happy to help.
